# 🚀 AI 智能简历调优系统 (Agentic Resume Optimizer)

一套基于 Agent 架构的智能简历生成与自动化评测系统，针对中国招聘生态（Boss直聘 / 大厂官网）深度适配。

## 系统架构

```
用户输入 JD + 个人履历底库
        │
        ▼
┌─────────────────────────────┐
│   JD Decoder（风险检测）      │  ← 黑话翻译 + 暗坑狙击 + 匹配度评级
└─────────────┬───────────────┘
              ▼
┌─────────────────────────────┐
│   Memory Module（记忆系统）   │  ← 本地 JSON 持久化：雷区词汇 / 能力边界 / 行文偏好
└─────────────┬───────────────┘
              ▼
┌─────────────────────────────┐
│   Resume Generator（生成器） │  ← 双渠道策略：Boss直聘版 / 大厂官网版
└─────────────┬───────────────┘
              ▼
┌─────────────────────────────┐
│   LLM-as-a-Judge（评测系统） │  ← 5维打分：关键词命中 / 破冰力 / STAR密度 / 反幻觉 / HR点击率
└─────────────┬───────────────┘
              ▼
         评分 < 85?
        ┌───┴───┐
       Yes      No
        │        │
        ▼        ▼
  Reflexion    输出最终简历
  反思重写
```

## 核心功能

| 模块 | 说明 |
|------|------|
| **Memory（长期记忆）** | 基于本地 JSON 的跨会话用户偏好记忆，实现能力边界锁定、雷区词汇过滤、行文偏好学习 |
| **LLM-as-a-Judge（自动评测）** | 5维度自动打分 Pipeline，替代人工逐条审查 |
| **Reflexion（反思重写）** | 评分不达标时自动截取批评、注入缺失关键词、触发重写循环 |
| **双渠道适配** | Boss直聘（推荐算法+破冰话术）vs 大厂官网（关键词初筛+STAR解析） |

## 技术栈

- **前端**：Streamlit
- **后端**：Python
- **模型接入**：OpenAI 兼容协议（当前接入 Xiaomi MIMO API）
- **记忆存储**：本地 JSON
- **开发方式**：Vibe Coding（Claude Code / Antigravity 自然语言驱动开发）

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（在 .env 文件中）
DEEPSEEK_API_KEY=your-api-key
MIMO_MODEL_NAME=MiMo-V2.5

# 3. 启动
streamlit run app.py
# 或双击 run.bat（Windows）
```

## 项目背景

本项目源于个人求职场景中的真实痛点：JD 分析准确但简历改写缺乏个性化约束、生成质量无法量化。在前期 Coze Agent MVP 验证后发现效率瓶颈与记忆成本问题，遂重新设计并以原生代码全栈落地。
